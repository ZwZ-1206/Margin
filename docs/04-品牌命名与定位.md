# 「留白」品牌命名与定位方案

## 1. 命名阐释：「留白」如何体现产品价值主张

### 1.1 词源与隐喻转译

「留白」是中国传统绘画与书法的核心技法——**画面刻意不填满，方寸之间留着空白，意境才有了呼吸的空间**。宋人言「淡处不淡，空处不空」，空白不是没有内容，而是让真正重要的东西浮现。

把这个隐喻平移到数字时代：

| 传统绘画 | 数字生活 | 产品动作 |
|---|---|---|
| 过度填满的画面 | 被 App 和通知占满的一天 | 无意识地刷屏 |
| 留白 | 主动空出来的时间 | 放下手机 |
| 意境浮现 | 真实生活浮现 | 专注、阅读、陪伴、发呆 |
| 画家主动选择 | 用户主动选择 | 看见数据 → 自主决策 |

**「留白」这个词本身就是产品逻辑**：它既描述用户的问题（时间被填满），也描述产品的动作（留出空白），还描述产品的结果（生活更精彩）。一个名字讲完了整个价值主张。

### 1.2 相对原名 OffScreen 的三个升级

1. **从对抗到共建**：OffScreen（关掉屏幕）是戒断叙事，暗示「屏幕是敌人，你在忍耐」；「留白」是建设性叙事——不是为了少看手机而少看手机，**是为了给更精彩的生活腾地方**。前者制造焦虑，后者给出理由。
2. **从工具到气质**：工具名（OffScreen）让人联想到监控软件和戒网瘾中心；「留白」是审美词，自带东方、安静、自主的气质，与「温和干预、不恐吓」的产品性格一致。
3. **从描述到品牌**：留白有清晰的视觉资产（空白、缺口、呼吸感），「留白之环」（缺口 60° 的圆环）可直接演化为 Logo、进度环、启动页动画，形成可识别的品牌符号系统；OffScreen 则无从演化。

### 1.3 与标语的咬合关系

主标语：**「放下手机 为更精彩的生活留白」**

- 「放下手机」是**动作层**——具体、可执行、零门槛，用户听完知道该做什么；
- 「为更精彩的生活」是**理由层**——回答「凭什么让我放下」，把牺牲感换成获得感；
- 「留白」是**结果层**——命名回收，slogan 结尾落在品牌名上，广告语即品牌。

三个字各司其职，一句标语完成了「做什么—为什么—是什么」的完整说服链。

## 2. 产品定位说明

### 2.1 一句话定位

> **留白是一款帮你看见并安放屏幕时间的 Android 应用——它安静地记录、温和地提醒，把省下的时间还给生活。**

### 2.2 定位拆解

| 维度 | 表述 |
|---|---|
| **品类** | 屏幕时间管理 + 专注计时（数字健康工具） |
| **核心动作** | 看见（本地统计）→ 安放（专注计时）→ 回归（现实生活） |
| **目标人群** | 25–40 岁城市自我管理者：知道自己刷太多，但不需要被说教；愿意为「更好的自己」付时间，不愿为焦虑付费 |
| **人群反像** | 不面向需要强制管控的家长/企业场景；不做监控、不做社交排名、不贩卖焦虑 |
| **差异化** | ① 数据全本地、无账号无追踪；② 温和干预（默认关闭、可自选）；③ 东方留白美学；④ 完全免费无会员，赞助自愿 |
| **竞品差异话术** | 「别的工具告诉你错了多少，留白帮你想清楚什么是对的」 |

### 2.3 品牌人格

像一位**安静的朋友**，不是教练，不是法官：
- 说话用「不如休息一下」，不用「你又沉迷了」；
- 数据缺口会说「部分数据为估算值」，不假装精确；
- 不推送恐吓式文案，不用红字惩罚；
- 尊重离开：随时导出、一键清空、卸载即消失。

## 3. 品牌文案建议

### 3.1 标语体系

| 层级 | 文案 |
|---|---|
| **主标语** | 放下手机，为生活中的其他精彩留白 |
| 副标语 A（功能向） | 看见屏幕时间，安放专注时刻 |
| 副标语 B（态度向） | 少看一会儿手机，多陪一会儿生活 |
| 副标语 C（商店短句） | 完全免费的屏幕时间与专注工具 |
| 赞助语 | 留白完全免费。如果它帮到了你，可以请开发者喝杯咖啡 ☕ |

### 3.2 分场景文案（替代原版的恐吓式表达）

| 场景 | 原版风格（弃用） | 留白版 |
|---|---|---|
| 超额提醒 | 「你的拿起次数已经超过上限」 | 「今天已经拿起手机 68 次，要不要休息一下？」 |
| 连续使用 | 「已经连续使用屏幕 %s」 | 「连续看了 %s 了，窗外看一眼吧」 |
| 专注中断 | 「专注被中断啦」 | 「这次专注到这儿也很棒，已记录 %s」 |
| 限额达成 | 「%s 的使用已达限额」 | 「%s 今天陪你的时间够久了，先到这里」 |
| 空状态 | 「暂无数据」 | 「还没有记录，从一次专注开始吧」 |
| 权限引导 | 「请完成权限设置」 | 「开启使用情况访问，留白才能帮你看见时间」 |
| 数据导出成功 | 「备份成功」 | 「备份已保存，你的数据始终跟着你走」 |
| 完成庆祝 | 「完成专注啦！」 | 「这一次，你把时间留给了自己」 |

### 3.3 应用商店描述（首屏）

> 你的屏幕时间，值得被温柔对待。
> 留白把你每天的手机使用安静地记录下来，用专注番茄钟帮你把注意力收回来。
> 没有账号，没有广告，没有会员——所有功能对所有用户免费。
> 放下手机，为生活中的其他精彩留白。

### 3.4 官网与物料统一口径

- 网站标题：留白 · 放下手机，为生活中的其他精彩留白
- 页脚固定句：© 2026 留白 · 完全免费 · 无会员 · 无广告 · 数据只属于你
- 图标/启动页：「留白之环」缺口 60°，缺口处一粒光点——**光点代表被你省下、正在回到生活里的时间**
- 语气总则：陈述优于感叹，建议优于批评，留白优于填满（文案本身也要「留白」——能短则短）
