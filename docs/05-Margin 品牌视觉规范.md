# Margin 留白 · 品牌视觉规范

> 中文名：留白 ｜ 英文名：**Margin**
> 主标语：**放下手机，为生活中的其他精彩留白**
> 英文标语：**Make room for life.** / *A little less scrolling. A little more living.*

---

## 一、为什么是 Margin

英文 **Margin** 与中文「留白」取自同一个动作：在纸上、在时间里，主动留出不被填满的那一块。

- **Margin（页边距）**——排版里最不起眼却最关键的留空。没有边距，文字会挤到纸的边缘，读者窒息。
- **留白**——中国画里不着笔墨之处，是"无"却撑起整幅画的呼吸。

两者的共通点是：**留出的空白不是浪费，而是让内容成立的前提**。这正是一款数字健康应用想说的话——减少屏幕时间不是惩罚，而是为生活腾出可用的边距。

命名价值主张一句话：**不是戒掉手机，而是给生活留出版心之外的空白。**（对抗式 → 共建式的叙事转换）

## 二、概念图的方向定义

参考概念图确立三条视觉准则，贯穿官网与 App：

### 1. 奶油纸底，不是纯白

纯白是屏幕的语言；奶油色是纸的语言。纸让人慢下来，纸有边距。

| 角色 | 值 | 说明 |
|---|---|---|
| 页面底 | `#F1EEE7` | 暖纸，带极其轻微的黄 |
| 卡片底 | `#FFFFFF` | 纸上的纸，靠阴影分层 |
| 分割线 | `#E6E1D6` | 极淡，存在但不抢戏 |
| 墨色 | `#1B1915` | 不是纯黑，是墨，避免刺眼 |

深色主题对应转换为**墨青系**（`#12151B` 页面 / `#191D25` 卡片），保持同样的"低饱和、非纯黑"原则。

### 2. 手写体只用在名字上

`Margin` 字标使用手写体（英文：Snell Roundhand / Segoe Script / Bradley Hand；中文：行楷 / 楷体）。手写体只出现在品牌字标与启动页，**绝不用于正文**——正文必须是可以长时间阅读的无衬线体。

原因：手写传递"人"的痕迹与温度，但可读性差；把它限制在名字上，正好契合"这是一封手写的便签，而不是一份系统通知"的气质。

### 3. 细线分隔，而非卡片堆叠

概念图用两条极细横线把字标夹在中间。这条规则落到 UI 上就是：

- 分区优先用**1px 细线 + 留白**分隔，而不是处处加卡片边框
- 卡片只在需要可点击/可操作时出现
- 每屏至少保留 20% 的空白区域不承载任何信息

## 三、字标（Wordmark）

### 标准组合

```
A LITTLE MORE ROOM TO LIVE        ← caption，字距 0.28em，全大写，三級灰
────────────────────────────────   ← 1px 细线
Margin  留白                       ← 英文手写 clamped 44–64px + 中文 20px 字距 0.34em
Make room for life.                ← body-m，斜体，次级色
A little less scrolling.
A little more living.
────────────────────────────────   ← 1px 细线
```

### 使用规则

| 场景 | 用法 |
|---|---|
| 官网 Hero / 启动页 | 完整组合（kicker + 字标 + tagline + 双细线） |
| 顶栏 / 导航栏 | `留白` + 下方小字 `Margin`（`small` 元素，10px，字距 0.2em） |
| 应用图标 | 单独使用「留白之环」图形，不带文字 |
| 正式标题 | `Margin 留白`（英文在前、中文在后，中间一个半角空格） |
| 禁止 | 拉伸、描边、加投影、改字距、把手写体用于正文 |

## 四、品牌图形：留白之环

**形状**：一个圆环，正上方留 60° 缺口，环的末端有一个光点随进度移动。

**含义**：闭合的环代表被填满的一天；缺口是主动留给生活的白。光点是此刻——你已经走过的那一段。

**参数**

| 项 | 值 |
|---|---|
| 缺口角度 | 60°（正上方居中，即 240°→300° 为缺口） |
| 起点 | 300°，顺时针绕 300° |
| 环宽 | 直径的 7.3%（220dp 时 16dp；260dp 时 18dp） |
| 端头 | 圆头（StrokeCap.Round） |
| 光点 | 直径 = 环宽 × 0.84，中心白点 × 0.32 |
| 进度 | 0–1 映射为弧长；>1 时整环转为警示色（超额） |
| 动画 | 640ms，`cubic-bezier(0.2, 0, 0, 1)` |

**应用位置**：首页今日进度、专注计时器、桌面图标、分享卡片角标。

## 七、语气（Tone of Voice）

| 该说 | 不该说 |
|---|---|
| 今天屏幕 4 小时 12 分，比昨天少 26 分钟 | 你今天又浪费了 4 小时！ |
| 你已经专注 25 分钟，要不要休息一下？ | 坚持住！不要放弃！ |
| 这段时间没有数据，开启权限后会自动累积 | 数据缺失，统计失败 |
| 放下手机，去享受这段留白 | 恭喜完成！太棒了！🎉 |

原则：**陈述事实，不做评判；提供选择，不做催促。**
数字健康类产品最大的失败是让用户产生羞耻感——羞耻会让人卸载，而不是改变。

## 八、落地检查清单

- [ ] 应用图标使用「留白之环」自适应图标（前景白环 + 叠翠底）
- [ ] 启动/首页出现 Margin 字标组合（手写体 + 双细线）
- [ ] 所有数字启用等宽数字
- [ ] 深色主题非纯黑，分类色切换为提亮版
- [ ] 浅色/深色文字对比度 ≥ 4.5:1（正文）与 ≥ 3:1（大字）
- [ ] 文案无羞辱、无催促、无感叹号轰炸
- [ ] 每屏保留 ≥20% 空白
